INSTALL

npm install @florianwenzel/daemonling

import '@florianwenzel/daemonling';

<daemonling-sprite id="p" size="90"
  variant="classic"
  style="bottom:110px"></daemonling-sprite>

Variants: classic · chip · blob · terminal · daemon · packet · cursor — switchable at runtime via p.variant = 'daemon'. Body color via the color attribute, any CSS color (dark by default, the sign stays dark).

The slide container needs position:relative. The figure itself is transparent and never blocks clicks on the slide.

CONTROL (ALL METHODS RETURN PROMISES)

const p = document.getElementById('p');
await p.spawn(300);          // pops up at x = 300
await p.walkTo(1400);        // walks there, faces the direction of travel
await p.showWord('MUTEX');   // holds up the sign, keeps breathing
await p.hideWord();          // sign back down
await p.zombie();            // eyes turn to crosses, tilts over
await p.terminate();         // shake → explosion → gone
p.despawn();                 // gone instantly, no explosion
